# 🌾 Ферма

Простая мобильная браузерная игра-ферма. Один файл `index.html`, без зависимостей — открой в браузере телефона.

**Как играть**
- Выбери семена внизу и нажимай на пустые грядки, чтобы посадить.
- Когда урожай созрел — нажми на грядку (или «Собрать всё»).
- Днём к прилавку приходят покупатели: нажми на покупателя, чтобы продать то, что он хочет. Быстрое обслуживание = чаевые 😊.
- Вечером лавка закрывается. Ночью растения не растут, покупателей нет — время улучшений: расширение участка, реклама, удобрения, вывеска, скамейка и новые культуры.
- Прогресс сохраняется в браузере автоматически.
